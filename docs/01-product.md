# 01-product.md

## 목표

팀 업무 시각화. "지금 누가 뭐 해?"가 사라지게 만든다.

## 페르소나

10명 규모 스타트업 팀리더 (30~40대)

## MVP 범위

- CRUD 4종 모두 화면에서 동작: 추가 / 목록 / 수정 / 삭제
- 상태 분류 + 마감 시각(`due_at`) 지정 및 표시
  - 날짜만이 아니라 시간까지 표시 (예: `2026-12-31 18:00`)
- 라이트/다크 테마 토글 (localStorage에 저장)
- 모바일 반응형 (360px 기준)
- UI 톤: macOS 스타일 - 둥근 모서리, 부드러운 그림자, 반투명 카드, 시스템 폰트

## 확장 (MVP 이후)

- JWT 로그인
- 팀 기능
- Kanban 보드
- 채팅
- CI/CD

## 범위 외

- 외부 결제
- 네이티브 앱
- WebRTC
- 외부 캘린더 연동
- 파일 업로드
- WebSocket - MVP는 폴링 방식 사용, 확장 단계로 보류

## 성공 기준 (실습에서 눈으로 확인 가능한 것만)

- 새로고침해도 데이터가 유지된다
- 360px 화면에서 레이아웃이 깨지지 않는다
- CRUD 4종이 화면에서 정상 동작한다
- 테마 토글이 정상 작동한다
